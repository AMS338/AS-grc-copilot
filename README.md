# AS GRC Copilot

A practical GRC toolkit for cybersecurity risk management, ISO 27001 control tracking, audit evidence, and compliance reporting.

## Project Status
Early development — prototype in progress.

## Planned Features
- Risk assessment and risk register
- ISO 27001 control tracker
- Audit evidence management
- Risk treatment plans
- Management reports

## Disclaimer
This toolkit supports GRC workflows. It does not guarantee compliance or certification.
